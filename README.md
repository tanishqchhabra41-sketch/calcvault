# CalcVault 🔒

CalcVault is a hidden vault calculator application built using:

- Python
- C
- Flask
- HTML/CSS
- JavaScript

## Features

- Real calculator UI
- Hidden secret vault
- Custom secret code
- Private notes storage
- Python + C integration

## How It Works

- Normal users see a calculator
- Entering the secret code opens a hidden vault
- Users can save private notes
- Users can change their own secret code

## Technologies Used

- Flask
- C
- HTML/CSS
- JavaScript

## Run Locally

Install Flask:

pip install flask

Compile C file:

gcc calc.c -o calc

Run app:

python app.py
